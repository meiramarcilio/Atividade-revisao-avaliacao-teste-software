# Atividade de revisao para avaliacao de teste de software

Atividade de revisão para avaliação de teste de software
(Review for software test exam)

Aplicativo simples para praticar testes unitário, de integração e regressão.
(Simple app for practicing unit test, integration test and regression test.)

Instalações (package installation):
npm install --save-dev cypress http-server
sudo apt-get update
sudo apt-get install libgtk-3-0 libgbm-dev libnotify-dev libnss3 libxss1 libasound2t64 libxtst6 xauth xvfb

Comandos no terminal para rodar os testes (to run tests on terminal):
run test
npm start
npm run cy:run
